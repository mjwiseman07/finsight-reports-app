# WBP Findings & Evidence

## `xero-sandbox-findings.md`

Human-readable findings from the W0.5 spike. Feeds W1 Xero adapter design decisions
(currency, sign convention, forbidden-account preflight strategy).

Generated by `npm run wbp:xero-spike` — not checked in until after a successful local run.

## `xero-sandbox-raw/`

Full request + response evidence per test. Every POST body sent to Xero and every
response body (including HTTP status, headers, error messages) captured verbatim,
timestamped. These files are canonical evidence and MUST be committed alongside the
findings doc so the audit trail is complete.

## Regenerating

```bash
npm run wbp:xero-spike
```

Requires: `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `XERO_CLIENT_ID`,
`XERO_CLIENT_SECRET`, and `ACCOUNTING_TOKEN_ENCRYPTION_KEY` (tokens are `enc:v1:` at rest).
Xero connection `671afdab-...` must be `status='connected'` on tenant `ceaea696-...`
(Xero Demo Company US only).

## Post-run cleanup

Journals are posted as `Status='DRAFT'` on Xero Demo Company US. Purge from the
Xero UI: **Accounting → Advanced → Manual Journals → filter Draft → delete WBP W0.5 entries**.
